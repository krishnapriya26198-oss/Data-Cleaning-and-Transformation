# Excel Data Cleaning and Formatting Assignment

## Overview

This project demonstrates the use of Microsoft Excel to clean, organize, and format a product dataset. The assignment focuses on identifying data issues, correcting inconsistent information, removing duplicates, splitting and merging data, applying number formats, and using conditional formatting.

Each task was completed in a separate worksheet in the Excel workbook.

## Tasks Completed

### 1. Handling Missing Values

The dataset was checked for missing values in the Price and Category columns.

- Missing price values were reviewed and handled appropriately.
- Missing category values were identified and addressed using the available information in the dataset.
- The final data was checked to make sure the missing values were properly handled.

### 2. Correcting Inconsistent Data

The Product Name and Category columns were reviewed for inconsistencies.

- Inconsistent text formats in the Product Name column were identified.
- Typographical errors and spelling mistakes in the Category column were corrected.
- Excel's Find and Replace feature was used to standardize the data.
- The final data was reviewed to make sure the values were consistent.

### 3. Removing Duplicates

The dataset was checked for duplicate rows.

- The entire dataset was selected when checking for duplicates.
- Duplicate records were identified.
- Duplicate rows were removed where necessary.
- The final dataset was checked to ensure that duplicate records were no longer present.

### 4. Splitting and Merging Data

The Product ID and product information were reorganized to make the data easier to work with.

- The Product ID was split into separate Manufacturing Date and Country Code columns.
- Unnecessary characters were removed from the resulting data.
- The Brand Name and Product Name columns were combined into a new Product Brand column.
- The final columns were reviewed for accuracy.

### 5. Number Formatting

Appropriate number and date formats were applied to the dataset.

- The Price column was formatted as currency.
- The Manufacturing Date column was formatted using the `DD-MM-YYYY` format.
- The formatting was checked to ensure the values were displayed clearly and consistently.

### 6. Conditional Formatting

Conditional formatting was applied to make important information easier to identify.

- Data bars and/or color scales were applied to the Price column to visually compare product prices.
- A custom conditional formatting rule was created for the Category column.
- Cells containing the category "Electronics" were highlighted.

## Tools Used

- Microsoft Excel
- Find and Replace
- Remove Duplicates
- Text and data formatting
- Conditional Formatting
- Excel formulas and functions
